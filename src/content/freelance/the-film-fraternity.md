  A creative discovery & booking platform for India's film crews — think
  LinkedIn meets Behance, built for everyone behind the camera. Directors,
  cinematographers, editors, sound designers, and other film professionals
  publish rich portfolios, get discovered, and get hired, while creators can

  one place: a public creative portfolio, a talent discovery + booking

  cinematic "camera-report" design language.

Built end-to-end, including:

- JWT authentication with Google OAuth and password reset
- Creator profiles with project galleries
- Search &amp; discovery across creators and listings
- A contact/inbox system between users
- Vendor-vs-individual equipment listings
- A booking/request flow with email notifications
- Real-time chat
- A fully responsive UI

Frontend built with React 19, Vite, Tailwind CSS, and TanStack Router &amp;
Query. Backend built with FastAPI, PostgreSQL, and SQLAlchemy, containerized
with Docker and deployed on the cloud.
